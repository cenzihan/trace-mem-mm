# 原生图文里程碑：冻结的 A/B/C 对照

数据为固定 HF revision `af912daba984e896e253016b7c7e334ef92c2a6f` 的 Mem-Gallery AI/Robotics 单场景：全部 185 rounds、370 条原始角色消息、31 张被引用原图与 57 个原生问题。所有 distractors 保留。49 题有检索 gold；另 8 题的检索 Recall 未定义，不计算为完美分数。人物 profile 未进入索引，原生日期保留来源 sidecar，没有推断时区或自然时间。

原图下载按固定官方源与精确 CDN 白名单处理，每张核验 LFS SHA-256、大小及完整解码，共 4,356,723 字节。原图/occurrence 与用于模型的派生图分开：LLM 输入为保留长宽比、长边不超过 1024 的高 detail 派生图，原图保持原字节供检索返回。图片未进入仓库，不将数据卡 MIT 声明泛化为第三方媒体再分发授权。可见人脸不做身份推断。

指定 gpt-4o-mini（实际版本 gpt-4o-mini-2024-07-18）在不见 QA/gold 的图像批次上一次输出全局描述、OCR、区域、关系、具名标签及不确定性。两套检索文本由同一份输出构成，真实 text-embedding-v4 256 维编码。A/B/C 共用同一原文、作者 caption、query 向量、100 个候选上限、30 MiB 解码媒体预算和 RRF 常数 60。原图参与写入、表示提取及返回；没有 reader 作答，不报告答题准确率或官方比赛成绩。

- A：原文、作者 caption、新全局视觉描述，BM25+dense/RRF。
- B：A 加 OCR/区域/关系和有来源依据的具名标签，BM25+dense/RRF。
- C：B 加有界同 session 顺序邻居及具名标签邻居，5 个 seed、最多 20 个邻居、固定融合权重 0.25。它不等于自然时间推理。

Fractional recall 是每题 `|retrieved∩GT|/|GT|` 的宏平均；any-hit 与 all-evidence 分开。K 在此为原生 round，多个消息或卡片不虚增证据。旧 caption-only 基线的 K 按 message，因此不能把两期分数直接相减当消融收益。@100 已覆盖超过一半 corpus，不能据其接近饱和就宣称系统解决了任务。

35 题有图像关联的 GT round；其图像关联证据 fractional recall@10 为 A 0.6857、B 0.6476、C 0.6619。它表示这些原图确实随对应 round 返回，所有返回图均核对原字节哈希，不等于视觉问答正确率。无 gold 的 8 题仍会获得 dense 候选，未实现或测量支持不足拒答。Top-1 误关联（有 GT 题但首条非任何 GT）分别为 23/49、27/49、35/49。

结论：结构卡及扩展没有稳定增益；C 在 @20 完整覆盖有所增加，但前排显著变差。不依据本场景改参数追分。B 会为无图 round 附加相同结构字段标记，这也可能改变向量，属于当前表示设计的混淆因素，须在下一次独立冻结消融中分离。

图像 query 修复的是局部过严文本子串规则：仅图片组成的合法 query，其 OCR/视觉文字不可能是空 query 文本的子串。现标为未核实视觉观察，仅用于瞬时检索，不写记忆；Add 的严格文本引用校验继续保留。真实原生图像预检成功处理了两条不在 query 文本中的视觉文字，未启用字节哈希排序。历史失败响应未留存，不能声称复原了旧输出原文。

原始“重启后重新编码、100 位全序相同”检查为 false，保持原记录。两次额外编码诊断发现：矩阵持久化未变，同一 query 向量跨重启全序相同；批量/单条编码最大绝对差约 0.000370、余弦 0.9999991，本次第 72 位首次交换，Top-20 顺序与 Top-100 集合相同。该诊断未改权重，也未重算冻结成绩，不把外部重新编码差异说成索引丢失。

本里程碑 58 请求（12 次 LLM、46 次 embedding），额外累计 preflight 5.3 元，低于 100 请求/20 元授权。估算 USD 0.07280490 加人民币 0.0210425 元。主流程 131.735 秒；检索核心延迟中位数 A/B/C 约 125/110/110 毫秒，排除批量 query 编码，不是线上单请求或 reader 端到端延迟。主流程 gpt 输入 466,958、输出 4,602 token，embedding 输入 41,861 token；诊断另 224 embedding token。所有 58 次 HTTP 200，无自动重试。价格估算不是实际账单。

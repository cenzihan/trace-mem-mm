## 独立八图适配器的离线验证

新增 `agent_memory/visual_batch8.py`，没有更改冻结三图 analyzer 或 A/B/C prompt。
固定 `gpt-4o-mini`、官方 Chat Completions 端点、`detail=low`、最多八图、2048 输出 token。
请求变体最长边必须不超过 512；原图与请求变体各留 SHA256，原始字节由独立内存对象保留。
相同 blob 的多次 occurrence 保留不同来源；发送给模型的标签只有局部 IMAGE 序号，不发 native 身份标签。

测试覆盖返回乱序后按 index 归位、重复/缺失/布尔 index、缺字段/额外字段、Unicode 字节上限、截断、拒绝、
未知模型、非法输入、请求被修改、原图与缩放变体关联，以及假 HTTP 超时/429/5xx 后预算仍占用。
已知响应可离线重新验证，不发新请求；异常只显示类别，已知响应保留在私有内存中。
这是契约可行性，未验证真实模型能稳定输出八条描述。
2048 token 可能容不下八条最长描述，遇截断失败停止，不自动拆批重试或拼造缺失事实。

该适配器尚未接入真实运行器：仍需持久化操作 journal 与受控私有响应保存/重启恢复，不能只靠内存做生产恢复。
当前原图输入复用协议校验，原图超过 10 MiB 仍不支持；后续须将本地大原图证据存储与请求变体准入分开，不能丢原图。
PIL 只验证本轮合成测试图像；没有新模型或下载。

现有 `video_evidence.py` 用六个中点抽帧，会遗漏未采样动作、完整顺序与音频。
它检测到音轨会明确拒绝，不会偷偷去音频后称完整支持；[gpt-4o-mini 不原生支持音频/视频](https://developers.openai.com/api/docs/models/gpt-4o-mini)。
音轨、语音/音乐、完整时间事件能力和受影响题数目前未知，不能判作零或静默删题。

## 费用复核与建议

[OpenAI Docs 图像计费规则](https://developers.openai.com/api/docs/guides/images-vision)给出 mini 每张 low 2,833 输入 token，
八图为 22,664。加明确 8,192 文本和 1,024 framing 余量，共 31,880 输入，最多 2,048 输出。
按 [模型价](https://developers.openai.com/api/docs/models/gpt-4o-mini)每百万输入/输出 $0.15/$0.60，
该包络为每次 $0.0060108；按 10 元/USD 的保守预算假设约 0.060108 元，不是市场汇率或实际账单。
传输层仍按完整 128k 输入预留，费用上界约 0.204288 元，因此每次 0.25 元 hold 覆盖现有门槛。
未计 prompt cache 或 Batch 折扣，未来按实际 usage 与账单核算。

[百炼指定 embedding](https://help.aliyun.com/zh/model-studio/embedding-interfaces-compatible-with-openai)每批最多 10 条、每条 8,192 **token**，
0.0005 元/千 token；满批上界 0.04096 元，因此每批 0.05 元 hold。
本地 8,192 **UTF-8 字节**是额外保守准入，不是官方 token 限制；没有安装官方 tokenizer，不能把本地分词数称计费 token。
N0 源文本 12,999,278 字节，按保守字节/token 包络仅源编码约不超过 6.499639 元；这不是报价账单。
全部 regular+Hard 共 1,044 个 query，另按实际 UTF-8 字节统计。新视觉描述的分块数须重新测量，不能直接假定等于 Qwen 文本。
实际 query 合计 87,755 UTF-8 字节，同样保守包络约 0.0438775 元；源+query 合计约 6.5435165 元。
这个包络既不是精确 tokenizer 结果，也不含 reader/judge/新视觉费用；完整任务预算仍按各调用满上下文 hold 保留。

旧两个方案保持为**条件性预占**：SGM 全库共享编码/全部 query/31 题双 reader 共 1,284 请求、79.20 元；
重建视觉表示方案 2,154 请求、296.70 元，其中 870 次处理 6,957 张原图/抽帧，成功 pilot 应计入并缓存。
两者都没有执行。ATM 当前向量缓存为 0；不能拿 Mem-Gallery 缓存冒充已编码 ATM。
同一源 flat cache 供方法共享，键含 namespace、revision、规范文本 hash、模型、维度和表示版本；视觉缓存另含 prompt、detail、请求变体 hash。
公开脱敏邮件中的 Qwen 改写属于数据集制作，不能据此自动判定系统违规，但必须披露；
296.70 元方案只能称“对发布输入以指定模型重建视觉表示”，不是从未脱敏个人原件开始的全流程，也未解决音频。

建议下一步先选**完整 11,034 来源 BM25 + 候选集内延迟 embedding**的低成本研究对照：
预先固定 20 题，每题 Top100 的 union 最多 2,000 个来源，保持全库候选不变；
约 202 次 embedding、40 次 A/C reader、8 次代理 judge，总上限 250 次/22.10 元预占。
它是外部 SGM 条件，不是全局 dense 或严格原图版，并受 BM25 第一阶段召回限制。
若目标必须是全局 dense，可改为一次共享源编码，但不应三份表示重复付费。

需要父线程先决定：采用哪一研究条件及其有界预算；确认数据传输字段与个人信息处理范围；
对视觉原图另完成媒体审核、音轨/解码器范围、大原图存储和持久化恢复。
没有必要先批准整个 296.70 元计划。本轮到此停止，旧 guard 保持关闭，不申请新凭据或更换指定模型。

可复核统计：`reports/atm-admission-audit.json`。新测试只用合成 fixture/fake HTTP；不产生新 benchmark 分数。

# Bounded image detail candidate

Based on the fixed v4.3.10 successful service. This independent ablation requests
high detail for the same at-most-eight JPEG512 previews (including the query).
It does not add images, enlarge the pool, alter text prefixes, prompts, index
contracts, same-Add neighbors, exact-image inclusion or returned originals.
Text-only requests are byte-for-byte equivalent at the payload level.

Hypothesis: low-detail visual reading can lose distinguishing labels or features
needed by direct or linked evidence retrieval. This is not a diagnosis of any
official failure and does not address text-only selection mistakes. The candidate
may increase image token use and latency; actual usage must be measured using the
original ledger. Existing budget gates and the human-approved retry policy apply.

Quality qualification requires fresh independently authored visual controls,
a two-source link, direct-text retention and an absent-subject control. No official
protected inputs or answers may be inspected for this purpose. This source alone
has no real qualification or official score. Do not replace production until the
candidate is actually qualified and all track/version gates are met.

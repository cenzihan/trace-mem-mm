# 学术榜硬约束与本项目实验边界

核查日期：2026-10-25。来源：[官网 Competition FAQ 05](https://agentmemoryleaderboard.ai/competition/)；[第二期 FAQ，2026-09-20，Q9](https://agentmemories.ai/blog?post=phase2-faq-20260920)。Competition 文字本轮直接读取；动态 Blog Q9 由父线程 fresh 核查并传入，本执行环境的 web 抓取未成功，不伪称已本地取到全文。

Embedding 固定 text-embedding-v4，LLM 相关组件固定 gpt-4o-mini。官网明确 Reranker 不作限制，因此 Qwen3-VL-Reranker-2B 可作为**纯候选相关性打分/重排**的独立消融，不需要再加“须组委会单独批准 VLM 身份”的门槛。此前该门槛是我们的保守解释，现撤销。它仍不得生成 caption、抽取记忆、当 embedding 或回答器。当前运行配置关闭 Qwen 是为了本轮对照清楚和控制资源，不是官网禁止；本轮没有新增 GPU 请求。

公开子集/样例允许用于理解任务、接口预检及评测复现；不能笼统要求公开 Mem-Gallery/ATM-Bench 原生评估另获书面许可。仍需来源和许可证清晰、版本冻结、gold 隔离，不用公开测试答案训练/微调参评系统或针对题目过拟合。正式评测时传入的受保护材料另按仅当前评测及必要审核、禁训练/产品分析/重建/传播的限制处理。

学术榜模型身份还涵盖外部预处理：ATM 预生成 Qwen SGM 不能冒充严格 gpt-4o-mini 路线。若研究外部预处理条件，必须单列并明确模型来源；严格主路线使用许可允许的原始媒体和指定 LLM 重建描述。原生数据卡许可不自动准许个人媒体外发，当前没有向 API 发送这些公开数据。

本地库的 reranker 显式开关表示启用已确认的 scoring-only 配置，不应解释为需要另取组委会批准。模型和预算门槛继续生效；公开仓库、报名、创建服务凭据及公网部署是独立行动，未因上述数据/模型公告自动获准。
